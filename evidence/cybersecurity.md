# Goal 2 — Cybersecurity Learning and Cisco Certificate

## Why I chose this goal

Cybersecurity is relevant to the kind of software and AI applications I want to work on. Applications can handle user inputs, personal information, credentials, and connections to other services, so I need to understand how to protect them. My learning plan focuses on authentication, access control, common vulnerabilities, secure coding, and data protection.

## What I have completed

I have completed the cybersecurity modules in my subject and earned a Cisco cybersecurity certificate. My subject learning covered the following concepts:

- **Authentication:** checking who is accessing a system.
- **Access control:** making sure users or processes can only access what they are permitted to.
- **Vulnerabilities:** recognising weaknesses that could be exploited.
- **Secure coding:** writing code in a way that reduces avoidable security risks.
- **Data protection:** handling information carefully and limiting unnecessary exposure.

Completing the subject modules and earning the Cisco certificate are important evidence of progress towards this goal. These concepts are also relevant to AI applications. For example, an application that connects to a model API needs to protect its credentials and handle user information responsibly.

## Reflection

This learning has helped me understand why security needs to be considered throughout development, rather than left until the end. Even if an AI model works as expected, the application around it could still have weaknesses. Exposing an API key or failing to validate inputs could create problems.

I have completed the learning activities and earned the certificate, so my progress is beyond an introductory understanding of the topic. My next challenge is to demonstrate how I can apply these principles in a practical development task, rather than only describing the concepts.

## Progress
